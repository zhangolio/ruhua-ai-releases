# 入画AI公开下载与更新

这是“入画AI工作台”的公开二进制发布仓库，用于提供安装包、便携包、校验和、Tauri 签名更新包与 `latest.json`。

入画AI为“先行版 · 永久免费”的非开源软件。本仓库不包含产品源码，也不授予复制、修改、反编译或再分发源码的许可。

## 当前状态

- 0.7.0 已完成 macOS 与 Windows 入仓前复验。
- GitHub Actions 构建额度恢复前，不在此仓库发布未经完整复验的安装包。
- 正式资产发布后，请只从本仓库的 [Releases](../../releases) 页面下载。
- 每个正式版本会同时提供 SHA-256 校验和；应用内更新还会校验 Tauri 更新签名。

## 安全说明

请勿从非官方转载地址下载入画AI。发现下载文件、更新清单或签名异常时，请通过 [入画AI官网](https://ruhuaai.com) 联系作者，不要继续安装。
